Making a classic game look stunning without impacting its atmosphere.

## Instructions

For now we have no publicly distributed binaries since we don't<br> 
want to lock down the engine yet.<br>

For the time being you will need to install UPBGE game engine form:<br>

https://upbge.org/#/

After installing UPBGE download the .blend game file from this github page:<br>

https://github.com/Complex5ystems/RTGI-Garry-s-MOD.-/blob/main/main/RTGI%20Garry's%20MOD.blend

Then open it in UPBGE and your done! Click "P" while hovering over the window to start.

> [!IMPORTANT]
> This is in MASSIVE beta, it currently has no<br>
> world editing mechanics or a custom physics gun.<br>
> Currently we are working on optimising the RTGI engine<br>
> for the live physics required and used by Garry's mod.
